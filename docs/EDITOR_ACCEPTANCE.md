# 人工作业编辑器实机验收

验收二进制：`target\release\repl-app.exe`。本轮只验收编辑器；除 E7 外不要点击“开始复刻”。
建议先复制 `examples\sample-job.json`，所有保存测试都操作副本。

## E0：MAA 资源路径

1. 进入“作业编辑”，确认顶部显示当前 MAA 资源路径和加载状态。
2. 点击“选择…”，先取消对话框；确认路径和地图保持不变。
3. 再次点击，选择 MAA 的 `resource` 目录，确认显示“已加载”；也可选择它的上一级 MAA 目录，
   确认程序自动显示实际的 `resource` 路径。
4. 输入一个该资源中存在的关卡，确认逻辑地图立即出现；在编队搜索输入 `安`，确认干员候选立即出现。
5. 关闭并重新打开程序，确认路径仍然生效；检查 EXE 旁 `config.json` 的 `maa_resource_dir` 已更新。
6. 选择一个不含 `Arknights-Tile-Pos\overview.json` 的目录，确认显示选择失败，旧地图和干员搜索仍可用，
   `config.json` 中原路径不变。

通过标准：选择、取消、父目录归一化、原子持久化和当前窗口热刷新均符合预期；失败不覆盖旧资源，
整个过程只访问本地文件，不截图、不访问 AFA、不向游戏发送输入。

## E1：模式与零输入边界

1. 不启动游戏和 AFA，运行主程序。
2. 确认默认进入“作业编辑”，右上角显示 `ZERO INPUT / MANUAL TIMING`。
3. 新建、输入标题、添加动作并保存草稿。

通过标准：编辑功能可用；AFA 显示“编辑模式不探测”；没有游戏窗口也不报错；没有任何鼠标、键盘
或游戏焦点被程序接管。编辑模式不自动识别或录制鼠标操作。

## E2：无效草稿可保存但不可运行

1. 新建作业，只添加一个“部署”，不要填关卡、干员和部署格。
2. 确认底部显示错误，右侧为 `DRAFT // 有错误，禁止运行`。
3. 另存为 JSON，关闭后重新打开该文件。

通过标准：文件能够保存和重开，缺失字段仍保持缺失；切到“复刻执行”后“开始复刻”不可用。

## E3：基本打轴与历史

1. 输入关卡标识；在“编队干员”输入框键入 `安`，确认候选列表出现“安赛尔”“安洁莉娜”等本地
   MAA 目录结果。点击“安赛尔”添加，再验证已加入的名称不再重复出现；另手动输入一个自定义名称，
   确认仍可添加。整个过程不应要求游戏、AFA 或 OCR。
2. 把光标设为 120，依次添加部署、技能、撤退、注释。
3. 选择动作，在绝对帧中输入 `249` 并按回车；撤销一次应直接回到输入前的值，不得先出现 `24`
   或 `2`，重做一次应回到 `249`。再输入另一个值并点击输入框外，重复检查一次撤销粒度。
4. 在“召唤物 / 装置目标”中加入 `Mon3tr`。确认动作目标是下拉菜单：内容只有占位项、两名开局
   编队成员和 `Mon3tr`；`Mon3tr` 不得出现在 `opers`。确认部署方向只有上、下、左、右、无方向。
   分别选择并保存重开，检查值不变，且 JSON 写入 `frame_replicator.deferred_targets`。
5. 修改说明和部署 X/Y；确认键入期间不会逐字符增加撤销历史，按回车或点到框外后才形成一次修改。
6. 给前两个动作填写明显不同的帧数和坐标；编辑第一个后在两者间反复切换，确认属性面板显示的
   始终是当前动作自己的值，且没有把第一个动作的输入写入第二个动作。
7. 复制并删除一个动作；连续撤销、重做。
8. 创建两个同为第 180 帧的动作，用“同帧 ↑/↓”调整顺序。
9. 在编队栏回车改名，观察对应动作轨道和目标是否同步；引用中的干员不应被删除。

通过标准：动作按干员分轨，注释进入“输出 / 注释”轨，空目标进入“未分配”；撤销/重做和脏标记
正确；输入确认只形成一条历史；下拉项受控；动作切换不串值；同帧顺序可调且保存重开后不变。

## E4：逻辑地图与数值回退

1. 使用能够在 MAA `Arknights-Tile-Pos` 中匹配的关卡标识。
2. 选择部署动作，在逻辑地图上点一个可部署格。
3. 确认 X/Y 同步变化，保存重开后格子不变。
4. 临时输入一个不存在的关卡标识，再手填 X/Y。
5. 点击“+ 技能 / 装置”，不选择名称，直接在地图上选择一个装置格；确认动作进入“地图装置”轨，
   保存 JSON 后得到 `type: Skill` 和 `location: [x, y]`，且没有强制生成 `name`。
6. 在“召唤物 / 装置目标”加入 `留声机`，让另一个技能动作同时选择该名称和装置格；保存重开后
   名称与格子都保留，且不会要求为留声机建立部署栏头像绑定。
7. 对普通干员技能填写格子，再点击“清除格子（改为按名称定位）”；确认 X/Y 和地图选中状态清空，
   保存后该动作不再含 `location`。

通过标准：部署和技能都能使用地图或 X/Y；地图资源或关卡不可用时有明确提示，X/Y 仍可编辑；
装置技能按显式格子保存，普通干员技能可在“格子优先”和“按名称定位”之间切换。

## E5：尺子只读跟随

1. 启动 ArknightsCostBarRuler，但不要启动复刻。
2. 保持“跟随尺子”关闭，让尺子的累计帧发生变化；“尺子绝对帧”仍应低延迟连续更新，光标帧不动。
3. 打开“跟随尺子”，让尺子的累计帧继续变化。
4. 在某一帧添加动作，再关闭跟随并手改光标。

通过标准：尺子连接时始终显示最新累计绝对帧，刷新应接近实时；跟随打开时光标与它同步，新动作落在
当时光标帧；关闭后实时帧继续更新而光标可手调。整个过程不暂停/恢复游戏、不调用 AFA、不注入输入。

## E6：未知字段往返

1. 在作业副本顶层、`doc`、某个 `opers` 和某个 `actions` 对象中各手工加入一个自定义字段。
2. 用编辑器打开，修改标题和动作帧，另存为新文件。
3. 用文本编辑器检查新文件。

通过标准：四处自定义字段和值均保留；已修改的标准字段正确更新。

## E7：有效作业交接

1. 把关卡、编队和所有动作错误修完，允许保留黄色警告。
2. 确认右侧变为 `READY // 可切到复刻执行`，保存并切到“复刻执行”。
3. 只检查作业标题、动作列表和“开始复刻”门禁，不实际开始；随后切回编辑器。

通过标准：复刻页显示同一份作业；只有 AFA、尺子和暂停战斗等原有条件同时满足时开始按钮才可能
启用。复刻尚未运行时可以切回编辑器；复刻运行期间编辑页签应不可用。

## E8：窗口与文件体验

1. 在最小窗口、默认窗口和放大窗口下查看时间轴、诊断和属性面板。
2. 测试中文文件名、中文干员名和较长说明。
3. 覆盖保存一次，再重开确认 JSON 完整。

通过标准：没有控件重叠到无法操作，没有崩溃或乱码；覆盖保存后文件可解析且不存在残留 `.tmp`。

验收时请记录失败的步骤号、截图、作业 JSON 和 `replicator.log`。不要覆盖失败现场；把这些材料交回
即可定位。编辑器 E1–E8 与复刻链路验收相互独立；M8 已于 2026-07-29 通过，当前构建 M9 已由用户
于 2026-07-30 确认 10/10 通过，但这不能替代编辑器 GUI 验收。
