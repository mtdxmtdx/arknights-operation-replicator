# 人工作业编辑器实机验收

验收二进制：`target\release\repl-app.exe`。本轮只验收编辑器；除 E7 外不要点击“开始复刻”。
建议先复制 `examples\sample-job.json`，所有保存测试都操作副本。

## E1：模式与零输入边界

1. 不启动游戏和 AFA，运行主程序。
2. 确认默认进入“作业编辑”，右上角显示 `ZERO INPUT / MANUAL TIMING`。
3. 新建、输入标题、添加动作并保存草稿。

通过标准：编辑功能可用；AFA 显示“编辑模式不探测”；没有游戏窗口也不报错；没有任何鼠标、键盘
或游戏焦点被程序接管。编辑模式不自动识别或录制鼠标操作。

## E2：无效草稿可保存但不可运行

1. 新建作业，只添加一个“部署”，不要填关卡、干员和部署格。
2. 确认底部显示错误，右侧为 `DRAFT // 有错误，禁止运行`。
3. 另存为 JSON，关闭后重新打开该文件。

通过标准：文件能够保存和重开，缺失字段仍保持缺失；切到“复刻执行”后“开始复刻”不可用。

## E3：基本打轴与历史

1. 输入关卡标识；添加两名编队干员。
2. 把光标设为 120，依次添加部署、技能、撤退、注释。
3. 选择动作，修改绝对帧、目标干员、说明、部署 X/Y 和朝向。
4. 复制并删除一个动作；连续撤销、重做。
5. 创建两个同为第 180 帧的动作，用“同帧 ↑/↓”调整顺序。
6. 在编队栏回车改名，观察对应动作轨道和目标是否同步；引用中的干员不应被删除。

通过标准：动作按干员分轨，注释进入“输出 / 注释”轨，空目标进入“未分配”；撤销/重做和脏标记
正确；同帧顺序可调且保存重开后不变。

## E4：逻辑地图与数值回退

1. 使用能够在 MAA `Arknights-Tile-Pos` 中匹配的关卡标识。
2. 选择部署动作，在逻辑地图上点一个可部署格。
3. 确认 X/Y 同步变化，保存重开后格子不变。
4. 临时输入一个不存在的关卡标识，再手填 X/Y。

通过标准：有效关卡显示地面/高台格并可点选；地图资源或关卡不可用时有明确提示，X/Y 仍可编辑。

## E5：尺子只读跟随

1. 启动 ArknightsCostBarRuler，但不要启动复刻。
2. 打开“跟随尺子”，让尺子的累计帧发生变化。
3. 在某一帧添加动作，再关闭跟随并手改光标。

通过标准：跟随打开时光标与尺子累计绝对帧同步，新动作落在当时光标帧；关闭后可手调。整个过程
不暂停/恢复游戏、不调用 AFA、不注入输入。

## E6：未知字段往返

1. 在作业副本顶层、`doc`、某个 `opers` 和某个 `actions` 对象中各手工加入一个自定义字段。
2. 用编辑器打开，修改标题和动作帧，另存为新文件。
3. 用文本编辑器检查新文件。

通过标准：四处自定义字段和值均保留；已修改的标准字段正确更新。

## E7：有效作业交接

1. 把关卡、编队和所有动作错误修完，允许保留黄色警告。
2. 确认右侧变为 `READY // 可切到复刻执行`，保存并切到“复刻执行”。
3. 只检查作业标题、动作列表和“开始复刻”门禁，不实际开始；随后切回编辑器。

通过标准：复刻页显示同一份作业；只有 AFA、尺子和暂停战斗等原有条件同时满足时开始按钮才可能
启用。复刻尚未运行时可以切回编辑器；复刻运行期间编辑页签应不可用。

## E8：窗口与文件体验

1. 在最小窗口、默认窗口和放大窗口下查看时间轴、诊断和属性面板。
2. 测试中文文件名、中文干员名和较长说明。
3. 覆盖保存一次，再重开确认 JSON 完整。

通过标准：没有控件重叠到无法操作，没有崩溃或乱码；覆盖保存后文件可解析且不存在残留 `.tmp`。

验收时请记录失败的步骤号、截图、作业 JSON 和 `replicator.log`。不要覆盖失败现场；把这些材料交回
即可定位。编辑器 E1–E8 与复刻链路验收相互独立；M8 已于 2026-07-29 实机通过，M9 仍待执行。
