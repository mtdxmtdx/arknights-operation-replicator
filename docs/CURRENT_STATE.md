## 现役实现与已验证成果

- AFA 负责自动开局暂停、普通暂停/恢复、`33ms` 逐帧、暂停技能和暂停撤退；Rust 负责部署拖拽、
  鼠标定位/停靠和单次 AFA 热键触发。`33ms` 已是预检必需项，失败时不回退旧 Rust 时序。
- 第 0 帧“开始复刻”执行两次人工焦点交接、编队绑定和新尺子样本接管；Runner 不发送开局暂停，
  也不自动抢游戏焦点。动作前持续复核尺子，动作后只接受新水位上的目标帧可信暂停样本。
- Pulse 收尾、运行期 Pause 帧宽限和 Resume running 回执均有状态机回归覆盖；同帧动作分别使用
  新样本水位，最终 Finish 为零输入。
- `afa-step-test.exe` 与主复刻使用同一个 AFA `33ms` 热键，最多派发 500 次并由尺子稳定结算每次
  0/1/≥2 帧结果；缺少热键会让主程序预检失败。旧的“首动作至少第 60 帧”误判也已从规则、
  验收文档、示例作业和编辑器诊断中移除，尺子越过目标时的安全中止仍保留。
