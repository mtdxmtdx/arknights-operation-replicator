# Pulse 收尾必须具备稳定证据

## 状态

已接受（2026-07-28）

## 决定

逐帧 Pulse 不能以脉冲发出后的第一条 `paused` 样本直接结算。若尺子观察到 `running`，只有后续
的新 `paused` 才能结束事务；若未观察到 `running`（空脉冲或采样漏掉中间态），必须连续收到
两条新 `paused` 才能结算。任意运行样本都会清空暂停候选计数。

## 原因

尺子分析管线可能在输入发出前已经捕获暂停画面，但在输入之后才给它分配更大的 `frame_id`。
实机因此出现 `paused(旧) → running(真实) → paused(最终)`。旧逻辑把第一条 paused 当作最终状态，
Machine 随即进入动作阶段；尚未落地的 Pulse 随后继续推进一帧。

## 后果

- 空脉冲结算需要多等一条暂停样本，但不增加任何输入。
- 正常看到 `running → paused` 的 Pulse 不增加确认样本数。
- Pulse 未稳定时状态机只允许继续 `AwaitFrame`，不得发下一脉冲、补发 Pause 或派发动作。
- 日志记录候选暂停、首次运行中间态和最终结算证据，供实机时序复核。
